# 파이썬 실행 방법 정리

파이썬을 처음 공부하면 Python, VS Code, Jupyter, Anaconda 같은 이름을 함께 접하게 된다. 모두 파이썬과 관련이 있지만 하는 일은 다르다. 어떤 것은 코드를 실행하고, 어떤 것은 코드를 작성하는 화면을 제공하며, 어떤 것은 필요한 프로그램을 한꺼번에 설치해 준다.

이 문서는 코드를 실행하는 기본 과정부터 시작해, 도구 선택과 파이썬 버전 관리, Docker까지 설명한다. 예제는 주로 Windows의 PowerShell을 기준으로 한다.

## 1. 파이썬 코드를 실행하려면 무엇이 필요한가

다음 코드는 화면에 문장을 출력한다.

```python
print("파이썬 실행 확인")
```

`print`는 괄호 안의 내용을 출력하는 파이썬 기능이다. 이 문장을 파일에 적는 것만으로는 실행되지 않는다. 코드를 읽고 처리하는 프로그램이 필요하다. 그 프로그램을 **파이썬 인터프리터**라고 한다. 보통 “파이썬을 설치한다”는 말에는 이 프로그램을 설치한다는 뜻이 포함된다.

내 PC에서 파일을 실행하는 과정은 다음과 같다.

1. 파이썬을 설치한다.
2. 편집기에서 코드를 작성한다.
3. 코드를 `hello.py` 같은 파일로 저장한다.
4. 파이썬에 그 파일을 실행하도록 요청한다.
5. 화면에서 결과를 확인한다.

`.py`는 파이썬 코드 파일에 사용하는 확장자다. 편집기는 글이나 코드를 작성하고 저장하는 프로그램이다. IDLE이나 VS Code가 여기에 해당한다.

Colab처럼 다른 컴퓨터에 준비된 파이썬을 사용하는 서비스도 있다. 이 경우 내 PC에 파이썬을 설치하지 않고 브라우저에서 코드를 실행할 수 있다.

## 2. 코드는 어디에 입력하는가

파이썬을 공부할 때는 **파이썬 코드**와 **프로그램 실행 명령어**를 서로 다른 곳에 입력할 수 있다는 점을 먼저 알아두면 좋다.

| 입력할 내용 | 입력하는 곳 | 의미 |
|---|---|---|
| `print("파이썬 실행 확인")` | 코드 파일, 파이썬 입력 창, 노트북의 코드 칸 | 파이썬이 처리할 코드 |
| `python hello.py` | 터미널 | 파이썬으로 파일을 실행하라는 명령 |

**터미널**은 프로그램 실행 등의 작업을 글로 지시하는 창이다. Windows의 PowerShell이나 명령 프롬프트가 그 예다. 시작 메뉴에서 PowerShell을 검색해 열 수 있다.

터미널에서 `python`을 입력하면 파이썬이 시작되고, 입력을 기다리는 `>>>` 표시가 나타날 수 있다. 그때부터는 파이썬 코드를 입력한다. `exit()`를 입력하면 파이썬이 종료되고 다시 터미널 명령을 입력할 수 있다.

> 예제의 `>>>`는 입력 위치를 보여 주는 표시다. 직접 입력할 코드에는 포함하지 않는다.

## 3. 두 가지 실행 방식

### 3.1. 파일로 저장해서 실행하기

편집기에서 다음 코드를 작성하고 `hello.py`로 저장한다.

```python
print("파이썬 실행 확인")
print(1 + 2)
```

터미널에서 이 파일을 실행하면 위에서부터 코드를 처리하고 다음 결과를 출력한다.

```text
파이썬 실행 확인
3
```

이처럼 파일에 저장한 코드를 실행하는 것을 **스크립트 실행**이라고 한다. 반복해서 사용할 코드나 여러 줄의 코드를 작성할 때 편리하다.

파일을 실행하려면 터미널이 어느 폴더에서 작업하고 있는지도 알아야 한다. 예를 들어 파일이 `C:\python-study`에 있다면 PowerShell에 아래 명령을 한 줄씩 입력한다. 예제 경로는 실제 파일을 저장한 폴더로 바꾼다.

```powershell
cd "C:\python-study"
python hello.py
```

`cd`는 작업할 폴더로 이동하는 명령이다. `python hello.py`는 “파이썬으로 현재 폴더의 hello.py를 실행하라”는 뜻이다.

Windows에서 `python` 대신 `py`로 파이썬을 실행할 수 있는 설치도 있다. 이 경우 두 번째 줄은 `py hello.py`로 입력한다. macOS·Linux에서는 설치 방식에 따라 `python3 hello.py`를 사용한다.

### 3.2. 입력한 코드를 바로 실행하기

파이썬 입력 창에서 코드를 입력하고 바로 결과를 확인할 수도 있다.

```pycon
>>> print(1 + 2)
3
```

이것을 **대화형 실행**이라고 한다. 짧은 코드를 시험하거나 문법을 배우는 데 편리하다.

Jupyter와 Colab에서는 한 줄씩 입력하는 대신 **셀**이라는 칸에 코드를 작성한다. 셀에는 여러 줄을 적을 수 있고, 원하는 셀을 따로 실행할 수 있다.

파일 실행과 대화형 실행은 모두 파이썬을 사용한다. 차이는 코드를 파일 전체로 실행하는지, 일부씩 실행하고 결과를 확인하는지에 있다.

## 4. 도구별로 하는 일과 사용 방법

### 4.1. IDLE: 간단한 코드 작성과 실행

IDLE은 파이썬 코드를 작성하고 실행하는 기본 도구다. [python.org](https://www.python.org/)에서 파이썬을 설치할 때, 설치 방식에 따라 함께 설치된다.

**Windows에서 IDLE 실행하기**

1. 작업 표시줄의 시작 버튼을 누르거나 키보드의 Windows 키를 누른다.
2. 검색 창에 `IDLE`을 입력한다.
3. 검색 결과에서 `IDLE (Python 3.x ...)`를 선택한다. 이름에 표시되는 숫자는 설치한 파이썬 버전에 따라 다르다.
4. `IDLE Shell` 창이 열리고 `>>>`가 표시되는지 확인한다.

`>>>` 뒤에 다음 코드를 입력하고 Enter를 누르면, 바로 아래에 `3`이 출력된다.

```python
print(1 + 2)
```

**검색 결과에 IDLE이 없다면**

시작 메뉴의 Python 폴더에 IDLE이 있는지 확인한다. 바로가기를 찾지 못했다면 PowerShell에서 다음 명령으로 실행할 수도 있다. 이 명령은 파이썬과 IDLE이 설치되어 있어야 동작한다.

```powershell
python -m idlelib
```

`python` 대신 `py`로 파이썬을 실행하는 환경에서는 `py -m idlelib`을 사용한다. `idlelib`을 찾을 수 없다는 오류가 나오면, 사용 중인 파이썬 설치에 IDLE이 포함되어 있는지 확인한다. python.org 설치 프로그램에서는 설치 변경 메뉴의 `tcl/tk and IDLE` 항목을 확인할 수 있다.

**IDLE에서 파일로 저장하고 실행하기**

Shell 창은 입력한 코드를 바로 실행하는 곳이다. 여러 줄의 코드를 파일로 저장하려면 별도의 편집 창을 연다.

1. `File > New File`을 선택한다.
2. 새 편집 창에 코드를 작성한다.
3. `File > Save`로 `hello.py`라는 이름으로 저장한다.
4. `Run > Run Module` 또는 `F5`를 누른다.
5. Shell 창에서 출력 결과를 확인한다.

처음 파일을 만들고 실행하는 과정을 배우기에 적합하다.

### 4.2. 터미널: 명령어로 실행하기

터미널은 코드 편집기와 별개의 도구다. 코드를 IDLE이나 VS Code에서 저장한 뒤, 터미널에서 `python hello.py`로 실행할 수 있다.

실행 방법이 명령어로 남기 때문에 같은 작업을 반복하거나 다른 사람에게 실행 절차를 전달하기 편리하다. 나중에는 외부 기능을 설치하는 작업도 터미널에서 하게 된다.

### 4.3. VS Code: 여러 파일을 다루는 편집기

VS Code는 코드를 작성하는 프로그램이다. **VS Code를 설치했다고 파이썬 자체가 설치되는 것은 아니다.** 파이썬과 VS Code를 각각 준비해야 한다.

또한 VS Code에 파이썬 관련 기능을 추가하는 **Python 확장**을 설치한다. 확장은 편집기에 기능을 추가하는 프로그램이다.

기본 준비 순서는 다음과 같다.

1. 파이썬과 VS Code를 설치한다.
2. VS Code 왼쪽의 확장 화면에서 Microsoft의 Python 확장을 설치한다.
3. 코드 파일이 있는 폴더를 VS Code에서 연다.
4. `Ctrl+Shift+P`를 눌러 명령 검색 창을 연다.
5. `Python: Select Interpreter`를 검색하고 사용할 파이썬을 선택한다.
6. `.py` 파일을 열고 `Run Python File in Terminal`을 실행한다.

5번은 “이 코드를 어느 파이썬으로 실행할지” 정하는 단계다. 파이썬이 여러 개 설치되어 있으면 특히 중요하다.

VS Code에서는 코드를 작성할 때 다음 입력을 제안하는 자동완성 기능을 사용할 수 있다. 코드 실행을 중간에 멈춰 값을 확인하며 오류를 찾는 **디버깅** 기능도 제공한다.

### 4.4. Jupyter Notebook과 JupyterLab: 코드와 결과를 함께 기록하기

Jupyter에서는 코드, 실행 결과, 설명 글을 한 문서에 담는다. 이 문서를 **노트북**이라고 하며, 보통 `.ipynb` 파일로 저장한다.

예를 들어 첫 번째 셀에 데이터를 읽는 코드를 적고, 두 번째 셀에 표를 만드는 코드를 적을 수 있다. 결과는 각 코드 아래에 나타난다.

Jupyter Notebook과 JupyterLab은 이러한 노트북을 열고 편집하는 도구다. JupyterLab은 여러 노트북과 파일을 한 화면에서 다룰 수 있다. [공식 안내](https://jupyter.org/)

파이썬이 준비된 상태에서 Jupyter Notebook을 설치하고 시작하는 기본 명령은 다음과 같다. 터미널에 한 줄씩 입력한다.

```sh
python -m pip install notebook
jupyter notebook
```

첫 줄은 설치 명령이다. `pip`의 역할은 다음 절에서 설명한다. 두 번째 줄을 실행하면 보통 브라우저에 Jupyter 화면이 열린다. 새 노트북을 만들고 코드 셀에 `print(1 + 2)`를 입력한 뒤 `Shift+Enter`로 실행한다.

브라우저에서 화면을 보더라도 위처럼 내 PC에서 시작했다면 코드는 보통 내 PC에서 실행된다.

노트북에서 코드를 실제로 실행하는 부분을 **커널**이라고 한다. 커널은 앞에서 만든 변수의 값도 기억한다. 예를 들어 다음 셀에서 `number`를 사용하려면 그 값을 정하는 셀을 먼저 실행해야 한다.

```python
number = 10
```

```python
print(number)
```

커널을 재시작하면 기억하던 값이 사라진다. 노트북 결과를 확인할 때는 커널을 재시작하고 위에서부터 모든 셀을 실행하면 순서에 따른 혼란을 줄일 수 있다.

### 4.5. Google Colab: 설치 없이 노트북 사용하기

Colab은 Google이 제공하는 온라인 노트북 서비스다. 화면은 내 PC의 브라우저에서 보지만, 코드는 기본적으로 Google이 제공하는 컴퓨터에서 실행된다.

1. [Google Colab](https://colab.research.google.com/)에 접속하고 로그인한다.
2. 새 노트북을 만든다.
3. 코드 셀에 `print(1 + 2)`를 입력한다.
4. `Shift+Enter`를 눌러 결과를 확인한다.

내 PC에 파이썬을 설치하지 않고 실습할 수 있다. 노트북은 Google Drive에 저장하고 공유할 수 있다.

Colab에서 코드 실행에 사용하는 환경을 **런타임**이라고 한다. 런타임은 계속 유지되는 개인 컴퓨터가 아니다. 사용하지 않거나 이용 제한에 도달하면 종료될 수 있다. 새 런타임을 받으면 변수, 추가로 설치한 기능, 임시 파일은 다시 준비해야 할 수 있다. 노트북 저장과 실행 중 만든 파일 저장은 별개이므로, 필요한 결과 파일은 Drive 등에 저장한다. [Colab FAQ](https://research.google.com/colaboratory/faq.html)

머신러닝 실습에서는 계산을 빠르게 처리하는 장치인 GPU를 사용할 수도 있다. 무료 서비스에서는 GPU 제공 여부와 사용 시간이 보장되지 않는다. [Colab FAQ](https://research.google.com/colaboratory/faq.html)

### 4.6. Anaconda와 Miniconda: 필요한 도구를 묶어서 설치하기

데이터 분석을 하려면 파이썬 외에도 여러 기능과 도구가 필요하다. Anaconda는 파이썬, 분석용 기능, Jupyter 같은 프로그램을 묶어서 설치하는 제품이다. 이렇게 프로그램을 묶어 제공하는 구성을 **배포판**이라고 부른다.

Anaconda에 포함된 Navigator는 설치한 도구를 선택해 실행하는 화면이다. 여기서 Jupyter 등을 시작할 수 있다.

함께 제공되는 **conda**는 필요한 기능을 설치하고 프로젝트별 환경을 관리하는 도구다. 환경을 나누는 이유는 6절에서 설명한다.

Miniconda는 파이썬과 conda 등을 포함한 최소 구성이다. Anaconda보다 함께 설치하는 항목이 적고, 필요한 기능은 직접 추가한다.

Anaconda의 이용 조건은 개인·조직과 사용 대상에 따라 달라진다. 조직에서 사용할 때는 [공식 이용 약관](https://www.anaconda.com/legal/terms/terms-of-service)을 확인한다. Miniconda도 사용하는 Anaconda 저장소에 따라 이용 조건이 적용될 수 있다. [공식 안내](https://www.anaconda.com/legal)

### 4.7. 그 밖의 도구

PyCharm도 파이썬 코드를 작성하고 실행하는 개발 도구다. 여러 파일을 관리하고 오류를 찾는 기능을 제공한다.

온라인 실행기는 웹사이트에 코드를 입력해 실행하는 서비스다. 짧은 코드 실험에는 편리하지만, 파일 저장이나 추가 기능 설치가 가능한지는 서비스마다 다르다.

## 5. 패키지 설치는 무엇인가

파이썬에는 기본 기능이 들어 있지만, 모든 기능이 포함되어 있지는 않다. 표 형태의 데이터를 분석하려면 pandas 같은 추가 기능을 설치해 사용할 수 있다.

이처럼 설치해서 사용하는 기능 묶음을 **패키지**라고 한다. 관련 설명에서 **라이브러리**라는 표현도 자주 보게 된다. 라이브러리는 다른 코드에서 가져다 사용하는 기능을 가리키며, 패키지 형태로 제공되는 경우가 많다.

### 5.1. 설치하기와 코드에서 사용하기

터미널에서 다음 명령을 실행한다.

```sh
python -m pip install pandas
```

명령의 각 부분은 다음 의미다.

| 부분 | 의미 |
|---|---|
| `python` | 파이썬 실행 |
| `-m pip` | 그 파이썬에 연결된 설치 도구 pip 실행 |
| `install pandas` | pandas 패키지 설치 |

설치가 끝나면 파이썬 코드에서 다음처럼 불러올 수 있다.

```python
import pandas
```

`import`는 설치된 기능을 현재 코드에서 사용할 수 있도록 불러오는 문장이다. 설치 명령은 터미널에, `import`는 파이썬 코드에 작성한다.

Jupyter나 Colab에서는 코드 셀에서 다음 명령으로 설치할 수 있다.

```python
%pip install pandas
```

`%pip`는 노트북에서 사용하는 특별한 명령이다. 일반 `.py` 파일에는 넣지 않는다.

### 5.2. 설치했는데도 사용할 수 없는 이유

컴퓨터에 파이썬이 여러 개 있으면 한 파이썬에 설치한 패키지를 다른 파이썬에서는 찾지 못할 수 있다. 따라서 설치할 때와 실행할 때 같은 파이썬을 사용해야 한다.

어떤 파이썬으로 실행 중인지 궁금하면 코드에서 다음을 실행한다.

```python
import sys
print(sys.executable)
```

`sys.executable`은 현재 코드를 실행하는 파이썬 프로그램의 위치다. VS Code에서 선택한 파이썬이나 노트북의 커널이 의도한 환경인지 확인할 때 사용한다.

## 6. 파이썬 버전과 가상환경은 왜 관리하는가

### 6.1. 파이썬 버전과 패키지 버전은 별개다

Python 3.11과 3.12는 파이썬 자체의 버전이다. pandas에도 별도의 버전이 있다.

오래된 프로젝트에서 사용하는 패키지가 새 파이썬을 지원하지 않을 수도 있다. 반대로 새 패키지는 일정 버전 이상의 파이썬을 요구할 수 있다. 그래서 프로젝트마다 필요한 파이썬과 패키지를 확인한다.

아래의 `3.12`는 설명을 위한 예시다. 실제 버전은 프로젝트에서 필요한 기능이 지원하는 범위에 맞춰 선택한다.

### 6.2. 가상환경으로 프로젝트의 패키지를 나누기

프로젝트는 하나의 작업에 사용하는 코드와 관련 파일을 모아 둔 것이다. 예를 들어 “매출 분석”과 “파일 정리 자동화”는 별개의 프로젝트가 될 수 있다.

한 프로젝트에서는 특정 패키지의 이전 버전이 필요하고, 다른 프로젝트에서는 새 버전이 필요할 수 있다. 모두 같은 곳에 설치하면 한쪽을 업데이트했을 때 다른 프로젝트가 동작하지 않을 수 있다.

**가상환경**은 프로젝트마다 패키지를 따로 설치할 수 있도록 나눈 공간이다. 보통 프로젝트 폴더 안의 `.venv`라는 폴더에 만든다. 이름의 `venv`는 가상환경을 뜻하는 virtual environment에서 왔다.

파이썬에 포함된 `venv` 기능으로 가상환경을 만들 수 있다. 다만 `venv`가 다른 버전의 파이썬을 다운로드하는 것은 아니다. 이미 설치된 파이썬을 사용한다. [Python venv 문서](https://docs.python.org/3/library/venv.html)

### 6.3. 가상환경을 만들고 실행하기

먼저 작업할 폴더에 `hello.py`를 저장한다. 그 폴더로 이동한 PowerShell에서 다음 명령을 실행한다.

```powershell
python -m venv .venv
```

현재 사용하는 파이썬으로 `.venv` 폴더에 가상환경을 만드는 명령이다.

생성한 환경의 파이썬을 직접 지정해 실행한다.

```powershell
.\.venv\Scripts\python.exe hello.py
```

`python.exe`는 파이썬 실행 프로그램이다. 앞의 경로는 현재 폴더 아래 `.venv\Scripts`에 있는 프로그램을 사용한다는 뜻이다.

이 환경에 pandas를 설치하려면 다음처럼 같은 파이썬 경로를 사용한다.

```powershell
.\.venv\Scripts\python.exe -m pip install pandas
```

처음에는 경로를 직접 지정하는 방법으로 어떤 파이썬을 사용하는지 확인하면 좋다. **가상환경 활성화**는 매번 긴 경로를 쓰는 대신 `python`이라는 짧은 명령으로 해당 환경을 사용하도록 터미널을 설정하는 작업이다. 위의 예제는 활성화 없이 실행할 수 있다.

VS Code에서도 이 환경을 사용하려면 `Python: Select Interpreter`에서 `.venv` 안의 파이썬을 선택한다.

### 6.4. 다른 파이썬 버전 사용하기

Windows에 Python 3.12가 설치되어 있고 `py`로 선택할 수 있다면 다음 명령으로 버전을 확인한다.

```powershell
py -3.12 --version
```

`--version`은 버전을 출력하는 옵션이다. 이어서 그 버전으로 가상환경을 만들 수 있다.

```powershell
py -3.12 -m venv .venv
```

이 예제는 아직 `.venv`를 만들지 않은 새 프로젝트 폴더에서 진행한다. 기존 환경을 다른 버전으로 바꾸려면 새로 만드는 것이 명확하다. 가상환경 폴더를 다른 컴퓨터로 복사하기보다는, 필요한 파이썬과 패키지를 다시 설치해 준비한다.

여러 파이썬 버전을 설치하는 도구로 **uv**를 사용할 수도 있다. [uv 설치 안내](https://docs.astral.sh/uv/getting-started/installation/)에 따라 uv를 설치한 뒤, 새 프로젝트 폴더에서 다음 명령을 실행한다.

```sh
uv python install 3.12
uv python pin 3.12
uv venv --python 3.12
```

| 명령 | 하는 일 |
|---|---|
| `uv python install 3.12` | Python 3.12 설치 |
| `uv python pin 3.12` | 이 폴더에서 사용할 버전을 `.python-version` 파일에 기록 |
| `uv venv --python 3.12` | Python 3.12로 `.venv` 생성 |

이후 실행 방법은 앞의 `.venv\Scripts\python.exe` 예제와 같다. `.python-version` 파일은 uv 등이 읽는 설정이며, 파일을 만들었다고 일반 `python` 명령이 자동으로 바뀌지는 않는다. [uv 버전 관리 문서](https://docs.astral.sh/uv/concepts/python-versions/)

### 6.5. 다른 사람에게 환경 전달하기

코드만 전달하면 상대방은 어떤 파이썬과 패키지를 준비해야 할지 모를 수 있다. 프로젝트 문서에 파이썬 버전을 적고, 필요한 패키지 목록도 함께 제공한다.

`requirements.txt`는 설치할 패키지를 한 줄씩 적는 파일이다. 패키지 이름만 적거나, `패키지이름==버전번호` 형식으로 특정 버전을 지정할 수 있다.

받은 사람이 그 목록대로 설치하려면 사용할 환경의 파이썬으로 다음 명령을 실행한다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`-r requirements.txt`는 파일에 적힌 목록을 읽어서 설치하라는 뜻이다.

## 7. Docker는 언제 필요한가

### 7.1. 파이썬과 패키지 외에도 필요한 것이 있을 수 있다

가상환경으로 파이썬 패키지를 나눌 수 있지만, 어떤 프로그램은 운영체제에 설치된 추가 프로그램이나 기능도 사용한다. 예를 들어 동영상을 처리하는 코드는 별도의 영상 처리 프로그램이 필요할 수 있다.

이 경우 파이썬과 패키지 버전만 맞춰도 다른 컴퓨터에서 실행에 실패할 수 있다. Docker는 이런 실행에 필요한 구성을 함께 준비하는 데 사용한다. [Docker 파이썬 안내](https://docs.docker.com/guides/python/)

### 7.2. 이미지와 컨테이너

Docker에서는 실행에 필요한 파이썬, 패키지, 파일 등을 **이미지**라는 형태로 준비한다. 그 이미지로 실행 공간을 만들면 **컨테이너**가 된다. 컨테이너 안에서 파이썬을 실행한다.

| 용어 | 의미 |
|---|---|
| 이미지 | 파이썬과 필요한 파일 등이 들어 있는 실행용 구성 |
| 컨테이너 | 이미지로 만들어 실제 프로그램을 실행하는 공간 |
| Dockerfile | 이미지에 무엇을 넣고 어떻게 실행할지 적는 파일 |

내 PC의 파이썬 버전이 3.13이어도, Python 3.12가 들어 있는 이미지로 컨테이너를 만들면 그 안에서는 3.12를 사용한다. 이 작업이 내 PC에 설치된 파이썬 버전을 변경하는 것은 아니다.

Docker를 내 PC에서 실행하면 컨테이너도 그 PC의 Docker 실행 환경에서 동작한다. 서버에서 실행하려면 그 서버에도 Docker와 필요한 이미지를 준비해야 한다.

### 7.3. 준비된 이미지로 파이썬 실행하기

먼저 Docker를 설치하고 실행해야 한다. Windows에서는 Docker Desktop을 사용할 수 있으며, 아래 예제는 Linux 컨테이너를 실행하는 설정을 기준으로 한다.

터미널에 다음 명령을 입력한다.

```sh
docker run --rm python:3.12-slim python --version
```

| 부분 | 의미 |
|---|---|
| `docker run` | 이미지로 컨테이너를 만들고 실행 |
| `--rm` | 실행이 끝나면 컨테이너 제거 |
| `python:3.12-slim` | Python 3.12가 들어 있는 간소한 기본 이미지 선택 |
| `python --version` | 컨테이너 안에서 파이썬 버전 출력 |

처음에는 이미지를 다운로드하므로 시간이 걸릴 수 있다. 완료되면 `Python 3.12.x` 형태의 버전이 표시된다. 여기서 `x` 부분은 이미지에 들어 있는 세부 버전에 따라 달라진다.

이 예제는 파이썬 버전을 확인하는 작업이다. 내 코드 파일을 실행하려면 그 파일도 컨테이너 안에 준비해야 한다.

### 7.4. 내 코드로 이미지 만들기

새 폴더에 다음 두 파일을 준비한다.

```text
작업 폴더/
  hello.py
  Dockerfile
```

`hello.py`에는 간단한 코드를 넣는다.

```python
print("Docker에서 파이썬 실행 확인")
```

`Dockerfile`은 확장자가 없는 파일이다. 다음 내용을 저장한다.

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY hello.py .
CMD ["python", "hello.py"]
```

각 줄은 다음 작업을 지정한다.

| 줄 | 의미 |
|---|---|
| `FROM python:3.12-slim` | Python 3.12가 준비된 이미지에서 시작 |
| `WORKDIR /app` | 컨테이너 안에서 작업할 폴더를 `/app`으로 지정 |
| `COPY hello.py .` | 내 파일을 이미지의 작업 폴더로 복사 |
| `CMD ["python", "hello.py"]` | 컨테이너가 시작되면 이 파일을 파이썬으로 실행 |

터미널에서 두 파일이 있는 폴더로 이동한 뒤 다음 명령을 입력한다.

```sh
docker build -t python-study .
```

**빌드**는 Dockerfile의 설명에 따라 이미지를 만드는 작업이다. `-t python-study`는 이미지 이름을 정하고, 마지막 `.`은 현재 폴더의 파일을 사용한다는 뜻이다.

이미지가 만들어지면 실행한다.

```sh
docker run --rm python-study
```

다음 결과가 표시된다.

```text
Docker에서 파이썬 실행 확인
```

`hello.py`를 수정해도 이미 만들어진 이미지 안의 파일은 바뀌지 않는다. 위의 빌드 명령을 다시 실행한 뒤 컨테이너를 실행해야 수정된 코드가 반영된다. [Dockerfile 작성 안내](https://docs.docker.com/get-started/docker-concepts/building-images/writing-a-dockerfile/)

### 7.5. 패키지도 이미지에 설치하기

pandas 같은 패키지가 필요하다면 앞에서 설명한 `requirements.txt`를 같은 폴더에 추가한다. Dockerfile은 다음과 같이 작성한다.

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN python -m pip install -r requirements.txt
COPY hello.py .
CMD ["python", "hello.py"]
```

`RUN`은 이미지를 만드는 중에 명령을 실행한다. 여기서는 패키지를 설치한다. `CMD`는 만들어진 이미지로 컨테이너를 시작할 때 실행한다. 설치와 코드 실행의 시점이 서로 다르다.

### 7.6. 가상환경과 Docker 중 무엇을 사용할까

| 상황 | 사용할 수 있는 방법 | 이유 |
|---|---|---|
| 내 PC에서 문법과 코드 실행 배우기 | 파이썬 + 편집기 | 기본 실행 과정에 집중 가능 |
| 프로젝트마다 패키지를 따로 설치하기 | 가상환경 | 다른 프로젝트의 패키지와 섞이지 않음 |
| 프로젝트마다 파이썬 버전도 다르게 쓰기 | 버전별 설치 또는 uv + 가상환경 | 필요한 파이썬을 선택해 환경 생성 |
| 팀과 서버에서 실행에 필요한 구성을 함께 맞추기 | Docker | 파이썬 외의 필요한 파일·프로그램도 이미지에 준비 가능 |

Docker는 처음부터 반드시 사용할 도구는 아니다. 파일 실행과 패키지 설치, 가상환경을 이해한 뒤 배우면 각 작업의 목적이 더 분명해진다.

Docker를 사용할 때는 두 가지를 기억한다. 첫째, `python:3.12-slim` 같은 이미지 이름은 업데이트되면서 세부 구성이 바뀔 수 있으므로 항상 완전히 같은 환경을 뜻하지는 않는다. 둘째, 컨테이너 안에만 저장한 파일은 컨테이너를 제거하면 사라진다. 결과를 남겨야 하는 작업에서는 컨테이너 밖의 폴더나 별도 저장 공간에 저장하도록 설정한다.

## 8. 실행이 안 될 때 확인할 것

### `python` 명령을 찾을 수 없다고 나온다

파이썬이 설치되어 있는지 먼저 확인한다. Windows에서 `py --version`이 동작하면 `py hello.py`로 실행할 수 있다.

파이썬이 설치되어 있어도 터미널이 실행 프로그램의 위치를 찾지 못할 수 있다. 프로그램을 찾을 때 참고하는 경로 목록을 **PATH**라고 한다. 설치 방식에 따라 PATH나 앱 실행 별칭 설정을 확인해야 한다. `python` 입력 시 Microsoft Store가 열리는 경우도 설치된 파이썬과 별칭 설정을 확인한다.

### 파일을 찾을 수 없다고 나온다

터미널이 작업 중인 폴더에 파일이 있는지 확인한다. 폴더가 다르면 `cd`로 이동하거나 파일의 전체 경로를 지정한다.

```powershell
python "C:\python-study\hello.py"
```

경로에 공백이 있어도 처리할 수 있도록 따옴표로 감싼다. 파일 이름이 실수로 `hello.py.txt`가 되지 않았는지도 확인한다.

### 패키지가 없다고 나온다

패키지를 설치한 파이썬과 코드를 실행하는 파이썬이 같은지 확인한다. 가상환경을 사용한다면 그 환경의 파이썬으로 설치하고 실행한다. VS Code의 인터프리터 선택과 노트북의 커널 선택도 확인한다.

### 노트북에서 같은 코드의 결과가 달라진다

셀을 실행한 순서가 다르거나 이전 실행에서 만든 값이 남아 있을 수 있다. 커널을 재시작하고 위에서부터 실행해 확인한다.

## 9. 어떤 순서로 배우면 좋은가

| 단계 | 먼저 해 볼 작업 | 배울 내용 |
|---|---|---|
| 1 | IDLE 또는 Colab에서 `print(1 + 2)` 실행 | 코드 입력과 결과 확인 |
| 2 | `hello.py`를 저장하고 터미널에서 실행 | 파일, 폴더, 실행 명령 |
| 3 | 필요한 패키지를 설치하고 `import` | 설치와 불러오기 구분 |
| 4 | 프로젝트 폴더에 가상환경 생성 | 프로젝트별 패키지 분리 |
| 5 | 필요한 파이썬 버전으로 환경 생성 | 파이썬 버전과 패키지 버전 구분 |
| 6 | Dockerfile로 이미지를 만들고 실행 | 실행 환경을 함께 준비하는 방법 |

코드를 작성할 화면과 실제로 실행할 파이썬을 구분하면 여러 도구의 관계를 이해하기 쉽다. 한 번에 모든 도구를 설치하기보다는, 현재 작업에 필요한 도구로 실행 과정을 익혀 나가면 된다.
